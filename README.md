Student Event Registration Formatter

Description
A Python console application designed to standardize messy student registration inputs for school events. It automatically cleans text fields (names, sections, and event titles) and formats numeric date inputs into a clean, readable output.

Features
- Removes accidental leading and trailing spaces using `.strip()`
- Standardizes capitalization using `.title()` and `.upper()`
- Generates an uppercase Name Code for official tracking
- Formats numeric year, month, and day inputs into a clear textual date using Python's built-in `datetime` module
